Página de Inscrição para Evento Online

Este é um projeto simples que consiste em uma única página HTML estática, criada para servir como um formulário de inscrição para um evento online. A página foi desenvolvida com HTML semântico para garantir estrutura e acessibilidade.

Sobre o Projeto

O objetivo deste projeto é fornecer um template básico e funcional para a coleta de dados de participantes de um evento. Ele inclui os elementos essenciais de uma página de captura, como um título, instruções, um formulário e informações adicionais sobre os palestrantes.

Observação Importante: Este é um projeto front-end apenas. O formulário coleta os dados visualmente, mas não há um back-end configurado para processar, salvar ou enviar essas informações. A ação do formulário (action="#") é um placeholder.

Funcionalidades

    📝 Formulário de Inscrição: Coleta nome, e-mail e consentimento dos termos.

    📋 Lista de Passos: Uma lista ordenada guia o usuário sobre como participar.

    🎤 Tabela de Palestrantes: Exibe a agenda do evento com os nomes dos palestrantes e os temas de suas apresentações.

    📱 Estrutura Simples: Código limpo e fácil de entender, ideal para estudos ou como ponto de partida para projetos mais complexos.

Tecnologias Utilizadas

O projeto foi construído puramente com HTML5, sem nenhuma dependência de CSS ou JavaScript.

Como Executar

Como se trata de um arquivo HTML estático, não há necessidade de instalação de dependências ou de um servidor web.

    Copie o código completo fornecido anteriormente.

    Salve-o em um arquivo com a extensão .html (por exemplo, index.html ou evento.html).

    Abra este arquivo em qualquer navegador de internet (como Google Chrome, Mozilla Firefox, Microsoft Edge, etc.).

A página será renderizada instantaneamente.

Estrutura do Código

O arquivo html está dividido nas seguintes seções principais dentro do <body>:

    Cabeçalho (<h1>): Título principal que chama a atenção para o evento.

    Passo a Passo (<ol>): Lista ordenada com as instruções para participação.

    Formulário (<form>): Seção interativa para a entrada de dados do usuário.

        input type="text" para o nome.

        input type="email" para o e-mail.

        input type="checkbox" para a aceitação dos termos.

        button type="submit" para o envio.

    Tabela de Palestras (<table>): Estrutura que organiza as informações sobre os palestrantes e os temas.
